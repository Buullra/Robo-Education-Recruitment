# Robo-Education-Recruitment

本仓库用于提交机协教学部纳新题的成果，内容包括一份内训课程设计方案和一份配套的授课型幻灯片，供评审查阅。

## 主要内容

- **内训选题**：机器人运动学入门——包含课程安排、可能遇到的问题与解决办法等内容
- **授课幻灯片**：围绕单片机的介绍制作的授课型幻灯片 Demo，讲解该主题的基本概念与核心知识点，预计授课时长约 10 分钟

## 文件结构

```

├── topic/
```
