# 机器人运动学入门 · 课程方案

## 课程基本信息

- **课程名称**：机器人运动学入门
- **面向对象**：大一学生
- **所需基础**：必要的线性代数知识，Python 知识基础
- **教学条件**：无需经费；场地为教室；学员自带笔记本电脑，配备编程软件

## 教学形式

- **预习**：课前发布预习视频/讲义
- **讲解**：梳理内容、剖析难点（40 min）
- **随堂练习**：准备 2–3 个问题，当堂做题（30 min），下一节课讲解（20 min）

## 实践环节

实现控制仿真机械臂的**取物 → 移物 → 放物**全过程。

## 课时安排

### 第 1 讲：刚体运动与位姿描述

- 坐标系
- 旋转矩阵的性质与复合
- 齐次变换矩阵：平移 + 旋转的统一表达
- 欧拉角 / 四元数（只做概念介绍）

### 第 2 讲：正运动学与 D-H 参数法

- 连杆与关节
- 四个 D-H 参数
- 相邻连杆变换
- 标准 D-H 建模流程

### 第 3 讲：逆运动学

- 逆解的存在性与多解性
- 平面 2R / 3R 的几何解法推导
- 数值迭代法思想简介

### 第 4 讲：雅可比矩阵与奇异性

- 关节速度 → 末端速度的映射
- 雅可比的几何直观
- 奇异位形
- 力 / 速度对偶（概念）

### 第 5 讲：轮式运动学

- 差速驱动模型
  - 正运动学：轮速 → 车速
  - 逆运动学：车速 → 轮速
- 与 AnyCar 巡线控制的衔接

## 可能出现的问题与对策

### 问题 1：学员数学基础、听课效果参差

**对策**：

- 每周发布预习视频 / 讲义
- 讲授时每个矩阵都配一张图
- 每节课后上传课程 PPT 以及笔记

### 问题 2：课程效果一般，学员不认真学习

**对策**：

- 随堂练习强制当堂提交（不完整没关系，批改结果仅供个人学习）
- 实践项目提交后由评委评价，并给出优秀学员示范
